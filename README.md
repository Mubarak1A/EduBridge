# EduBridge School Management App

A B2B2C school management application connecting schools, teachers, and students for streamlined administration and communication.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

---

## 🌟 Features

- **School Management:** Manage multiple schools and their data efficiently.  
- **Teacher & Student Management:** Register and manage teachers, students, and classes.  
- **Communication:** Facilitate communication between schools, teachers, and parents.  
- **B2B2C Approach:** Designed to serve both institutions (B2B) and individual users (B2C).  
- **Real-Time Updates:** Changes are reflected instantly across all users.

## 🛠️ Getting Started

### Prerequisites

- Node.js v18+  
- Package manager: npm, yarn, pnpm, or bun  

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Mubarak1A/EduBridge.git
cd EduBridge
```

2. Install dependencies:

```bash
npm install
# or
yarn
# or
pnpm install
# or
bun install
```

3. Start the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
